# 迭代紀錄：雨宮駅・春雨

每一輪都遵循同一個流程：

1. 修改 `index.html`
2. 用 Playwright（`tools/shoot.mjs`）以固定時間 `t=14.2`、1600×900 渲染截圖
3. 對照三個檢查項目自我審查：**電影感光影**、**大氣透視**、**色彩層次**
4. 用 `tools/analyze.py` 量化截圖（亮度分位數、飽和度、冷暖比例、上／中／下三帶的對比與飽和度），作為肉眼判斷的佐證
5. 列出問題 → 下一輪修正

每一輪的 HTML 快照與截圖都保存在 `iterations/round-N/`，可以直接開啟比較。

> 指標說明（皆為 sRGB 顯示值 0–1）：`p5 / p50 / p95` = 亮度 5% / 中位數 / 95% 分位；`contrast` = p95 − p5；`sat` = 平均飽和度；`warm / cool` = 明顯偏暖（R>B）或偏冷（B>R）的像素比例；三帶 `σ` = 該帶亮度標準差（細節與對比），`S` = 該帶平均飽和度。大氣透視良好時，中景帶（horizon）的 σ 與 S 應低於前景帶（fore）。
